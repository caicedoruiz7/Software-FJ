# Software FJ - Gestión de Clientes, Servicios y Reservas
Curso Programación (213023) - UNAD - Fase 4.

Ejecutar: `python main.py` (Python 3.8 o superior, sin librerías externas).

Archivos: `excepciones.py`, `registro.py` (logs), `entidad.py` (clase abstracta), `cliente.py`,
`servicios.py` (clase abstracta + 3 servicios), `reserva.py`, `main.py` (simulación).
No usa base de datos: solo listas. El archivo `eventos.log` guarda errores y eventos.
